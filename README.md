# Planner — 3D-тур ділянкою і планувальник посадок

Тривимірна модель реальної ділянки 20 × 25 м: можна пройтися нею «ногами», подивитися згори,
розставити дерева, кущі, квіти й меблі та побачити, як усе виглядатиме через 1, 5 чи 20 років
і де о котрій годині лежатиме тінь.

## Запуск

Збирати нічого не треба — це статичний сайт (three.js лежить у `vendor/`).

```bash
python3 -m http.server 8100
```

Далі відкрити <http://localhost:8100/>.

## Що вміє

- **Прогулянка** від першої особи, **Огляд** з висоти, **План** згори з сіткою та супутниковою підкладкою.
- **Каталог** рослин (плодові й декоративні дерева, хвойні, кущі, ягідники, квіти, ліани) і садових меблів.
- **Шкала часу** «через N років»: кожна рослина росте за власною кривою росту.
- **Сонце і тінь** для будь-якого місяця й години (широта 50°N, справжня орієнтація ділянки).
- **Порівняння з фото**: камера стає в точку, з якої зроблено реальний знімок, а знімок накладається поверх.
- План зберігається в браузері; є експорт та імпорт у JSON.

## Структура

```
index.html, css/, js/main.js, js/app/   застосунок (види, керування, планувальник, інтерфейс)
js/config/site.js                       обміри ділянки, наявні рослини й меблі, точки зйомки фото
js/world/                               земля, бруківка, паркани, будиночок, сарайчик, оточення, небо
js/plants/                              каталог рослин і процедурний генератор
js/items/                               меблі та спільний реєстр каталогу
assets/ground/, assets/photos/          запечені текстури землі; зменшені фото для порівняння
images/planner/                         вихідні матеріали: супутник, схема розмірів, фото
tools/                                  скриншоти (shot.cjs), запікання текстур (bake_ground.py)
docs/SURVEY.md                          опис ділянки: розміри, матеріали, кольори, як виміряно
CLAUDE.md                               правила проєкту й контракти модулів (для роботи з Claude Code)
```

## Як уточнювати модель

Усі розміри й координати — в одному файлі, `js/config/site.js` (метри від південно-західного кута:
`X` — на схід, `Y` — на північ). Змінили число — сцена перебудується сама. Джерело правди для пропорцій —
`images/planner/planCosmos.png`; як саме знято розміри, описано в `docs/SURVEY.md`.

Наступний крок якості — замінити процедурні моделі (будиночок, меблі, окремі рослини) на зроблені в Blender
(`assets/models/*.glb`): кожна модель створюється однією функцією-фабрикою, тож заміна не зачіпає решту коду.
